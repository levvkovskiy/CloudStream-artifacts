# CloudStream Artifacts

This repository contains public artifacts for LevkovskiyCloudStream CloudStream extensions.

## Purpose

This repository stores:
- `.cs3` plugin files
- `plugins.json` manifest
- `repo.json` repository manifest

These artifacts are automatically deployed from the private LevkovskiyCloudStream repository via GitHub Actions.

## Repository URL for CloudStream

Add this repository in CloudStream using:
```
https://raw.githubusercontent.com/levvkovskiy/CloudStream-artifacts/main/repo.json
```

## Providers

- **UASerials** - Ukrainian cinema with movies and series
- **UAFix** - Netflix content in Ukrainian
- **UAKino** - Ukrainian cinema with authentication
- **Rezka** - Ukrainian provider with dubbing

## Note

This is an automated artifacts repository. Do not manually edit files here.
All changes should be made in the main LevkovskiyCloudStream repository.
